# SA Management System Flutter

Flutter application for the SA Management System project.

## Run

```bash
flutter pub get
flutter run
```

## Project Structure

- `lib/src/screens` for app-level screens such as login and main shell.
- `lib/src/widgets` for shared UI widgets.
- `lib/src/theme` for colors and theme setup.
- `lib/src/modules/open_registration_and_subject_registration` for Module 1.
- `lib/src/modules/co_curriculum_activity_and_credit_claim` for Module 2.
- `lib/src/modules/tuition_fee_and_payment` for Module 3.
- `lib/src/modules/attendance` for Module 4.
